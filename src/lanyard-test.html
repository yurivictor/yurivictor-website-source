Camera
x y z — camera position (default 0, 0, 30). Lower z makes the card bigger.
fov — vertical field of view (default 20). Lower also makes it bigger.

Material
metalness — default here is 0.15. Upstream is 0.8, which greys out a white badge.
roughness — default 0.9.

Card
fit — cover or contain. Use contain if the memoji gets cropped.
width — lanyard band width.
back=reactbits — restore the atlas's stock back face. Default blanks it.
band — band colour (default #000). band=atom restores the React Bits texture.
tone=aces — restore R3F's default tone mapping, which caps white at ~236/255. Default is flat (none).

Interaction check
Hover the card — the cursor should become a grab hand. If it does not, pointer events are not reaching the mesh at all, which is a different bug from the drag itself failing.
